# 🏥 Hospital Management System using Java Collections Framework

## 📌 Overview

This project is a complete **Hospital Management System** built using the **Java Collections Framework**. It was developed as part of an 8-level healthcare hackathon challenge, where each level introduces different collection types and real-world hospital management functionalities.

The goal of this project is to demonstrate how various Java collections can be used effectively to solve real-world problems in healthcare management, including patient registration, doctor scheduling, emergency triage, pharmacy inventory management, insurance claims processing, and a centralized hospital dashboard.

---

## 🚀 Features

### Level 1 – Patient Registration

* Register new patients
* Prevent duplicate patient IDs
* Search patients by ID
* Discharge patients
* Emergency patient queue using LinkedList

### Level 2 – Doctor Scheduling

* Doctor registration and management
* Search doctors by specialty
* Appointment booking system
* Conflict detection for appointments
* Chronological appointment scheduling using TreeMap

### Level 3 – Patient Waitlist & Triage

* Emergency triage system using PriorityQueue
* Priority-based patient handling
* Duplicate admission prevention using HashSet
* Patient records sorting using TreeSet

### Level 4 – Bed Allocation System

* Allocate and release hospital beds
* ICU, General, Emergency, Pediatric, and Maternity wards
* Occupancy tracking
* Ward statistics using EnumMap

### Level 5 – Pharmacy Inventory

* Medication management
* Inventory tracking
* Low stock alerts
* Expiry monitoring
* Prescription management

### Level 6 – Lab Results & Analytics

* Store patient lab results
* Track patient trends
* Identify abnormal and critical results
* Statistical analysis and reporting

### Level 7 – Insurance Claims Processing

* Insurance claim management
* Claim status tracking
* Fraud and duplicate claim detection
* Provider-wise claim analytics

### Level 8 – Hospital Dashboard

* Complete system integration
* Real-time hospital statistics
* Doctor availability tracking
* Bed occupancy monitoring
* Pharmacy alerts
* Lab alerts
* Insurance claim summaries

## 🛠️ Java Collections Used

| Collection      | Purpose                       |
| --------------- | ----------------------------- |
| ArrayList       | Patient Registration          |
| LinkedList      | Emergency Queue               |
| HashMap         | Doctor Directory & Inventory  |
| TreeMap         | Appointment Scheduling        |
| PriorityQueue   | Emergency Triage              |
| HashSet         | Duplicate Patient Prevention  |
| TreeSet         | Sorted Patient Records        |
| LinkedHashMap   | Bed Allocation Tracking       |
| EnumMap         | Ward Statistics               |
| IdentityHashMap | Insurance Claim Deduplication |
